# GRAPH RUNNER 3.0

関数のグラフに沿って原点 `(0,0)` からゴール `(8,0)` まで進む、スマホとPCに対応した数学パズルゲーム。

## 遊び方

1. 入力欄を選択して、画面内の専用ボタンから数式を組み立てます。iPhoneでは通常のキーボードは出ません。
2. 入力した式のグラフがリアルタイムで表示されます。
3. 「走らせる」を押して、障害物を避けながらゴールを目指します。
4. 紫のリングがあるステージでは、**すべてのリングの指定した高さ**を通過する必要があります。
5. クリアすると次のステージが開放され、進行状況は同じブラウザに保存されます。

関数入力用のボタンは「数字・演算」と「関数・記号」に分かれています。指数、分数、三角関数、平方根、絶対値などが使えます。左右キーでカーソルを移動できます。式のタブは4本まで追加できます。

## ステージ

チュートリアルから始まり、3次関数、正弦波、絶対値、平方根、周期の異なる波の合成まで、合計12ステージです。
