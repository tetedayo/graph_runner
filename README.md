# GRAPH RUNNER 6.0 — 自由攻略とコイン回収

36の類似ステージを18個に再編成しました。決められた1本の数式を当てる必要はありません。

- 18ステージ：円形障害物、長方形の壁、広いゲート、コインを組み合わせた多様な問題
- コインは任意：ゴールまで安全に到達すればクリア。全コイン回収は追加の目標
- 各ステージの最高コイン回収枚数とクリアチェックをブラウザに保存
- 全ステージを最初から自由に選択できる
- iPhoneの画面内数式キーボードに対応
- 原点 (0, 0) からゴール (8, 0) まで、1本の関数で進む

## 以前の進捗について

ステージの内容・番号を一新したため、旧36問のチェックは新しい18問に自動で引き継ぎません。
旧進捗データは削除せず、別の保存キーを使って新18問のクリア状況と最高コイン枚数を記録します。
ブラウザのサイトデータを削除すると進捗は消えます。
