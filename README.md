# GRAPH RUNNER 6.0 — 自由攻略とコイン回収

36ステージを18個のバリエーション豊かなパズルに再編成しました。どのステージにも唯一の正解式はありません。

## ゲーム内容
- スタートは (0,0)、ゴールは (8,0)
- 円形障害物・長方形の壁・広い通過ゲートを避けて進みます
- 金色のコインは任意の追加目標。全回収なしでもゴールすればクリア
- 18ステージを最初から自由選択。ステージ一覧でクリアチェックと最高回収枚数を確認
- iPhone対応のボタン式数式入力。外部ライブラリなし

## セーブデータの注意
新しい18ステージは旧36ステージとは内容が異なるため、クリア記録の保存キーは別にしました。
以前の進捗を新ステージに誤って当てはめることはありません。以前の記録は削除していません。
新しいクリア記録とコインの最高回収枚数は同じ端末・ブラウザの localStorage に保存されます。
