# GRAPH RUNNER 4.0

関数のグラフを道にして、原点 `(0,0)` から `(8,0)` のゴールを目指す数学パズルゲーム。

## 変更点

- ステージを **12 → 36** に拡張。従来の12ステージも残しています。
- 13〜36には高難度ステージを24個追加しました。
- 三角関数の合成、振幅の変化、五次・六次多項式、絶対値、平方根、有理関数、指数、対数などが登場します。
- 5〜7個のゲートや狭い障害物が待ち構えています。
- 追加した全ステージについて、ゲーム内のパーサーと当たり判定ロジックを使い、解答例がクリアできることを検証済み。
- 以前のステージのクリア進捗（`graphRunnerUnlocked`）は引き継がれます。

## 遊び方

iPhone の Safari や PC ブラウザから [ゲームページ](https://tetedayo.github.io/graph_runner/) を開いてください。数式は画面内のボタンで入力できます。

## 公開

GitHub Pagesの `main` ブランチのルートから静的サイトとして配信します。`index.html` だけで動作します。
